Its reentrant lock covers the whole selected native method. Input/output/alias checks run at native entry points, not only at a voluntarily used wrapper. Return checks exact empty-party and unchanged-PC destination state, commits the original managed generation, writes/readbacks the original native payload and LEAVES THE FENCE CLOSED. Existing revoked objects are not reused or published. RESTORED is a managed phase, not player release. Ambiguous removals remain RESERVED; interrupted returns remain explicitly mismatched and quarantined without replay.
